# 私有流量管理后台（本地实现，尚未发布）

参考 link3 数据分析页的信息分组：今日/昨日概要、访问和点击趋势、链接点击排行、设备和来源分析。界面为本博客单独实现，没有搬用对方的私有代码，也不读取 link3 的数据。

## 本地使用

1. Node.js 构建博客：`npm run build`。
2. 首次设置独立管理员：`npm run admin:setup`，在终端交互输入账号密码；不将密码放在命令行参数中。
3. 运行 `npm run admin`，访问 `http://127.0.0.1:4322/admin/`。
4. 同一端口的 `/`、`/archive/` 是接入本地采集的完整博客预览。原来的 4321 静态预览服务继续保留，但不提供后台 API。

公开页脚的平台按钮旁设有登录入口：未登录显示“登录”，从此入口登录后返回原页面；已登录显示“进入后台查看 PV”和“退出登录”。跨标签页登录/退出会同步状态，后台仍以服务端会话作为权限依据。页脚 QQ 按钮只显示“QQ 交流群”，不显示群号。

本次演示如已生成临时管理员，登录信息仅在 `.private/analytics/local-login.json`，文件权限 600，不进入 Git。该临时密码只用于本地预览，不得复制为生产密码。管理员配置保存 scrypt 哈希及随机会话密钥，数据库是 `.private/analytics/traffic.sqlite3`。

## 登录与数据权限

- `/admin/` 的 HTML 由服务器检查登录会话后返回，直接访问未登录会跳转登录页；不能靠隐藏前端菜单绕过。
- `/api/analytics/summary`、`/api/analytics/export` 和 `/api/auth/session` 均检查服务端会话。访客 cookie 无权读取统计。
- 管理员会话为 HttpOnly、SameSite=Strict Cookie，生产 HTTPS 下附加 Secure，12 小时过期；退出后服务端撤销。
- 登录失败 5 次会对该来源暂停 15 分钟；写接口要求同源 Origin，退出还要求会话 CSRF token。
- 后台 HTML/API 不缓存，前端用 textContent 输出访客/页面数据，CSV 防止表格公式注入。
- 未登录公众只能向 `/api/analytics/visit`、`/api/analytics/click` 发送采集事件，拿不到聚合指标或访客明细。
- 公开页脚不再显示 PV/UV，原第三方计数器不再调用。

## 统计口径

- PV：同一浏览器、同一页面、北京时间当天只计一次；刷新、返回和重复标签页不会重复加数。去重由 SQLite 唯一约束执行。
- UV：区间内独立匿名浏览器标识数。跨设备、无痕窗口或清除 cookie 会视为不同访客，不能保证是现实中的不同人。
- 点击：同一浏览器、来源页面和目标链接当天只计一次；去掉目标查询参数与锚点，避免保存分享 token 等信息。
- 访客点击率：点击过链接的独立访客数 / 区间 UV，而非点击数除以 PV。
- 支持今日、近 7 天、近 30 天和最多 366 天的日期区间；展示真实空状态，不预置示例访问。
- 不保存访客原始 IP、完整 User-Agent、来源或目标查询参数；只保存匿名标识、页面、来源域名及设备类别。登录限流只保存地址的带密钥摘要。
- 基础识别排除常见爬虫；没有地理定位、收入分析，也不伪造地理/收入信息。
- 原不蒜子没有本站可迁移的逐日/页面/点击明细；新后台从自身采集启用后开始记录，不把旧总数冒充明细。线上旧统计仍维持原状，直到另获发布授权。

## 将来启用生产服务（待授权）

先通过用户明确“提交PR”进入 PR 流程，获准合并/发布后才安装与启用，不在本次执行。

- 静态站继续由 Nginx 服务，新增独立的 127.0.0.1:4322 服务处理后台和 API；不开放新公网端口。
- 先创建专用 `hanser-blog` 系统账号，安装本目录的 systemd 服务与博客专用 Nginx 片段，执行 Nginx 配置校验；不改动 fefw 的服务、数据或站点。
- 正式管理员配置为 `/etc/hanser-blog/admin.json`（专用账号拥有，权限 600）；`origin` 必须为 `https://hanser.fireemblem.top`，反向代理时设置 `trust_proxy=true`。
- 数据放在 `/var/lib/hanser-blog/traffic.sqlite3`，独立于发布目录。发布不导入本地账号/数据库，不清空线上访问记录。
- 发布布局调整为 `releases/<版本>/site` 和 `releases/<版本>/server`；Nginx 只公开 site/。新旧布局首次切换需另行审阅，不能仅切换当前符号链接。
- 代码回滚遵循 3 个版本总上限（当前 + 2 个回滚备份）；持久数据库与账号配置不参与发布目录清理。
- 只有管理员实际设置正式密码、会话密钥和持久数据路径后，才可以启用。不要把本地临时登录文件或 `.private` 复制到服务器。
